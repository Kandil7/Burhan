# Session Logs (`docs/learning/`)

This directory holds **session logs and the knowledge-system artifacts** that
the `project-log` tool writes (the tool is path-locked to
`<repo>/docs/learning/`).

The curated, numbered learning guides live in `docs/11-learning/`. Each
artifact type has exactly one home:

| Artifact | Home |
| --- | --- |
| Curated learning guides (file walkthroughs, deep dives, indexes) | `docs/11-learning/` |
| Session logs, decisions, walkthroughs written during work | `docs/learning/sessions/` |

Do not move files between the two; add new session logs under `sessions/`.
